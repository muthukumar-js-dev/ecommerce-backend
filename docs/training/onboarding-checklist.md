# Developer Onboarding Checklist

## Week 1: Environment Setup

### Day 1-2: Access & Tools
- [ ] GitHub access granted
- [ ] Slack channels joined
- [ ] AWS/Cloud access configured
- [ ] kubectl configured
- [ ] Docker installed
- [ ] Node.js 18+ installed
- [ ] MongoDB Compass installed
- [ ] Postman/Insomnia installed

### Day 3-4: Codebase Familiarization
- [ ] Clone repository
- [ ] Read architecture overview
- [ ] Run application locally
- [ ] Explore folder structure
- [ ] Review domain models
- [ ] Understand CQRS pattern

### Day 5: Development Workflow
- [ ] Create feature branch
- [ ] Make small code change
- [ ] Run tests locally
- [ ] Submit pull request
- [ ] Code review process

## Week 2: Deep Dive

### Architecture
- [ ] Study DDD implementation
- [ ] Understand event sourcing
- [ ] Review saga pattern
- [ ] Explore microservices

### Infrastructure
- [ ] Deploy to local Kubernetes
- [ ] Configure monitoring
- [ ] Set up Kafka locally
- [ ] Configure Redis

### Testing
- [ ] Write unit test
- [ ] Write integration test
- [ ] Run E2E tests
- [ ] Review test coverage

## Week 3: First Task

- [ ] Pick starter task from backlog
- [ ] Implement feature
- [ ] Write tests
- [ ] Submit for review
- [ ] Deploy to staging
